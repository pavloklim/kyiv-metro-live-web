# Kyiv Metro Live

Адаптивна вебкарта Київського метрополітену з розрахунковим рухом поїздів. Позиції детерміновано обчислюються з поточного київського часу, інтервалу руху, часу перегонів та зупинок.

## Запуск

```bash
npm install
npm run dev
```

## Модель руху

Модель використовує типові інтервали:

- 3 хвилини в ранкові та вечірні години пік;
- 5 хвилин удень;
- 7 хвилин увечері;
- 10 хвилин наприкінці роботи;
- 145–155 секунд на перегін та 25 секунд на зупинку.

Це розрахункова візуалізація, а не GPS-моніторинг. Параметри винесені в `schedule` у `src.js` і можуть бути замінені офіційними значеннями.

## Стек

- Vite
- Vanilla JavaScript
- SVG
- CSS animations

## Важливо

Це неофіційний експериментальний проєкт, не пов'язаний із КП «Київський метрополітен». Дані деморежиму не відображають фактичний рух поїздів.
