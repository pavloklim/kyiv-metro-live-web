# Kyiv Metro Live

Адаптивна вебкарта Київського метрополітену з анімованим рухом поїздів. Проєкт працює у деморежимі без бекенду та має точку інтеграції для дозволеного live API.

## Запуск

```bash
npm install
npm run dev
```

## Live API

Вкажіть URL джерела даних під час збірки:

```bash
VITE_METRO_API_URL=https://example.com/api/trains npm run build
```

Формат реального API буде зафіксований після підтвердження доступу та умов використання. До цього карта автоматично використовує локальну симуляцію.

## Стек

- Vite
- Vanilla JavaScript
- SVG
- CSS animations

## Важливо

Це неофіційний експериментальний проєкт, не пов'язаний із КП «Київський метрополітен». Дані деморежиму не відображають фактичний рух поїздів.
